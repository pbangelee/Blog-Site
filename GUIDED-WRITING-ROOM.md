# Guided Writing Room

See `CURRENT-UPDATE.md` first for the newest theme color migration and finished-entry preview.

## Install

Copy this folder's contents into the existing GitHub repository, replacing matching files and keeping subfolders intact. Commit and Push origin, then refresh after GitHub Pages deploys.

This interface needs no additional SQL. The previous notebook and organization upgrade is still required for Notebook and Organize your journal; existing writing features remain available without it.

## Write → Details & cover → Review

1. Open Entries, then continue a draft, edit a published entry, or choose New entry. Drafts and Published have separate tabs, with search and journey filtering.
2. Write the story. Text, Photo, Two photos, and Quote buttons are visible. Upload pictures directly where they belong. Move and remove controls appear beside every section. Photo cards show Choose photo or Replace photo, a caption beneath the image, and visual Centered, Full width, or Two together layouts. Descriptions and photo reuse live in More photo options. Removing a photo from the story keeps its uploaded file available.
3. Continue to Details & cover for the experience date, journey section, author, themes, introduction, cover photo, and uploaded photo library. These fields are visible without opening disclosures. Optional details can be left blank.
4. Continue to Review to check the details and actual reader layout. Use Desktop and Phone to compare reader widths in the same full preview.
5. Choose Publish entry or Update live entry when ready. Reaching Review alone never publishes anything.

Use the numbered steps or Back to return to earlier work. Save draft is available throughout; published entries instead offer Save changes privately. Saving keeps the current step open. After pausing, valid changes autosave privately. The save indicator reports progress or a connection failure; this requires an internet connection.

All entries and the workspace navigation save valid entry changes privately before leaving the editor. An untitled story requires a title to save, or confirmation before discarding it. Unfinished photo sections can be saved as drafts, but must be completed before publishing.

## Published entries

Editing a published entry opens its private working copy. Saved edits remain private until Update live entry is chosen in Review. View live entry, Unpublish to drafts, and Move to Trash are explicit controls beneath the editor. Every entry row also has Edit and Move to Trash, so opening the editor is unnecessary to delete it. Moving to Trash asks for confirmation and shows Undo. Undo restores as a private draft, including previously published entries, and never automatically publishes a private revision. Permanent deletion remains inside Trash.

## Notebook and settings

Notebook saves private pages and can copy a page into a new draft while preserving the original note. Organize your journal shows journey cards with Edit, Show/Hide, Browse entries, and reorder arrows. New sections offer Choose entries yourself or Use a date range. Theme cards use colored tags and keep names attached to their existing entries when renamed. Choose a manual section while editing an entry; republish existing published entries to share placement changes. Trash has no count in the navigation.

The public journal's fonts and design are unchanged. The Writing Room uses readable interface typography, a small handwritten logo, single-column mobile details, and larger touch controls.

## Validation

Automated workflow checks cover step navigation, saving on the same step, private previews, explicit publication, private revisions, inline photo uploads, autosave while typing, trash and restore, notebook saving and conflicts, organization, and older database compatibility. JavaScript syntax and local asset references are checked. Browser visual and physical-device testing remain to be done on the deployed site.
