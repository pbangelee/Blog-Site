# Sticky navigation and interactive details

Transparent desktop navigation becomes compact cream navigation on scroll. On mobile and smaller tablets it stays solid and sticky. Anchor jumps account for the measured header height.

The homepage title group is higher, with a stronger subtitle and subtle desktop scroll movement. Journey lines draw into view; theme outlines draw on hover or keyboard focus; entry photos have supplemental Read entry labels. Section numbers, fine rules and restrained curved linework add detail.

Links navigate immediately. Supporting browsers use native page crossfades; others use an incoming fade. Reduced motion disables decorative movement.
